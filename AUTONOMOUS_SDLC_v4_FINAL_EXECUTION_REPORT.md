## 🚀 Deployment Instructions

### Quick Start
```bash
# Clone repository
git clone https://github.com/terragon-labs/lm-watermark-lab
cd lm-watermark-lab

# Install dependencies (in virtual environment recommended)
pip install -e ".[all]"

# Run tests
python3 simple_core_test.py
python3 robust_generation2_test.py
python3 performance_generation3_test.py

# Quality validation
python3 quality_security_validation.py

# Basic usage
from watermark_lab import WatermarkFactory
watermarker = WatermarkFactory.create("simple", key="your_secret_key")
watermarked_text = watermarker.generate_text("Your prompt here")
```

### Production Deployment
```bash
# Docker deployment
docker build -t watermark-lab .
docker run -p 8080:8080 watermark-lab

# Kubernetes deployment
kubectl apply -f kubernetes/deployment.yaml

# Monitoring setup
kubectl apply -f monitoring/prometheus.yml
kubectl apply -f monitoring/grafana/
```
